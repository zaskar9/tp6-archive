SPORTTAG - SPORTS DAY SCORING
=============================
August 1993 to January 1994. Creates competition lists and rankings
for a school sports day: sprint (60/80/100 m), jump (high, long),
throw (ball, javelin, shot put).

SPORTDAY.PAS  program Sportstag, with ALLOTRIA, FILEHAND, LISTEN,
              RESULTAT (.INC)
SPORTOBJ.PAS  unit SportObj (screen objects); MOUSE.PAS (copy)
*.MEN         menus: EINGABE, ERGEBNIS, FILEHAND, HAUPT, LISTEN
HMENUE.DAT    main menu text
*.SPT         data: SCHUELER, SCH_O, SCH_U, SPORT, SVLEIST,
              SVLEIST2, SV9293 (school year 1992/93)
TESTSPOB.PAS, TASTE.PAS   test programs
SV.LZH        archive; CHKLIST.MS is a Microsoft Anti-Virus file

Not part of the program: HPTRANS.EXE/.CFG, F2400.EXE, NE.COM
(third-party tools found in the same folder).
