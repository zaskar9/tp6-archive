TETRIS - PROFESSIONAL TETRIS
============================
November 1993 to March 1994. Graphics mode, PCX title screen.

TETRIS.PAS   program ProfessionalTetris, with the includes
  PCXGRAPH TETRBUGS TETRINIT TETCOPYR TETRISCR TETRFELD TETRDRAW
  TEZUFALL TETSOUND TETMUSIK TETTASTE TEDREHEN TETPOINT (.INC)
TETRIS.EXE   build of 5 Dec 1993
TETRIS.PCX / TETRIS.PRW   title picture
SCORE.PCX / SCORE.PRW     score screen
GAMEOVER.PCX / .PRW       game over screen
TETRIS.ICO   Windows icon
BUGTEST.PAS, READBUG.PAS, READBUG.EXE   test programs

The Tetris melody as a Composer song is COMPOSER\SONGS\TETRIS.CMP.
