DRAW - PAINT PROGRAM
====================
Mouse-driven paint program in graphics mode, June to October 1993.

DRAW.PAS   program Drawing, with the includes CURSOR UNDELINE
           DRAWRECT CIRCDRAW FREEDRAW DRAWLINE SPACFILL ENDOF DELETE
           DRAWGUM DRAWMENU DRAWSCR (.INC); uses unit MOUSE
DRAW.EXE   build of 24 Oct 1993

Mouse experiments that led up to it (June 1993):
CURSOR.PAS (program MAUS), MAUSERI.PAS, EXPERIEN.PAS, KEYPR.PAS

SLIDMOUS.PAS  sliding piece puzzle, mouse only (June 1993, 31 KB)
