OBERFL - WINDOW OBJECTS
=======================
Experiments with a window class in BGI graphics that imitates a
Windows 3.1 window with title bar and menu bar.

WIN.EXE       13 Oct 1993. No source. Draws a window titled
              "Windows 3.1" at (100,100)-(600,400) using an object
              with the methods Init, Rahmen, TitleBar, MenuBar,
              MenuPlug, and tracks the mouse. Analysed by
              disassembly in Oct 2026; it is an earlier build of
              the OBERFL01.PAS experiment.
OBERFL01.PAS  program Oberflaeche, 31 Dec 1993: the Fenster object
              with exactly these methods.
OBJTEST.PAS   Turbo Vision test (Jul 1993)
