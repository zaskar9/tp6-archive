MGCCDOC - MGCC DOCTOR
=====================
System information tool, December 1993. Shows date and time, free
disk space, mouse driver, graphics card and Sound Blaster.

MGCCDOC.PAS  program MGCCDoctor, with MGCCCOPY, MGCCEXAM, MGCCRESU
             and SIGNET (.INC); uses MyUtil, Mouse, MyObject
MGCCDOC.EXE  build of 2 Dec 1993
MENU.DAT     is opened by the program but never shown: the Menu
             object is set up and not used again, a leftover of the
             HWTEST skeleton the program grew from. The file is not in
             the archive and the program runs without it.
