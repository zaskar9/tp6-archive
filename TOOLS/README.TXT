TOOLS - SMALL UTILITIES
=======================
SPEED.PAS     CPU speed test with a progress bar, rates the machine
              from "sehr schnell" to "sehr langsam" (Sept 1994).
              SPEED.EXE build.
DARK.EXE      20 Mar 1994. Runs a DOS command with the display
              switched off: DARK <command>. Blanks the screen via
              the VGA attribute controller, runs COMMAND /C with
              the argument, clears the screen and switches the
              display back on. No source survived.
DARK.PAS      reconstructed from DARK.EXE by disassembly, Oct 2026.
