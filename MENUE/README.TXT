MENUE - PROGRAM LAUNCHER "PROMENU"
==================================
Text-mode DOS menu to start the programs installed on the PC,
July/August 1993. CONFIG.MEN names it "ProMenu 7.0".

MENUE.PAS   program Menue, with HELPMENU, COPYRIGH, MENUMENU (.INC);
            uses units MYOBJECT and MOUSE
MENUE.EXE   build of 10 Aug 1993
CONFIG.MEN  configuration (drive, menu file)
MENU.DAT    the categories; one data file per category:
  BENUTZER.DAT  Benutzeroberflaechen: MS Windows, MS-DOS
  TEXTVERA.DAT  Textverarbeitung: Word fuer Windows 2.0b, ...
  PROGRAMM.DAT  Programmiersprachen: Turbo Pascal 6.0, Q-Basic
  SPIELE.DAT    Spiele
  LERNPROG.DAT  Lernprogramme
  DEMONSTR.DAT  Demonstrationen
  DOSPROMT.DAT  DOS-Prompt
  VIRENSCH.DAT  Virenschutz: Norton AntiVirus
OLD\MENU.DAT  an older menu file (Aug 1993)

These data files are a snapshot of the software on the PC in
July 1993.
