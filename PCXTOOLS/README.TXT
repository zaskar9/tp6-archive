PCXTOOLS - PICTURE TOOLS
========================
Tools for PCX pictures and the own PRW format, Nov 1993 to Apr 1994.
A .PRW file is the raw screen image converted from the .PCX of the
same name, loadable with one block read (see PRWREAD.PAS and MyUtil).

PCX_PAS.PAS   PCX reader (writes .TPP)        PCX_PAS.EXE
PRWREAD.PAS   reads and shows a .PRW picture
LOGO.PAS      program PCXUtils                LOGO.EXE
GRINTPIC.PAS  picture test                    GRINTPIC.EXE
DEMO.PAS      program DemoPCX, shows A:\COMP.PRW
TESTPCX.PAS, PUTIMAGE.PAS   tests

PICS\  the pictures: COMP, COMP2 (Composer title), COPY, ENTERTAI,
       FARB, G, KUPPEL, MGS, REKL, TEST, TRUMP (.PCX and .PRW),
       BILD.PCX, BILD2.PCX, RAHEL.PCX, RAHEL.TIF
