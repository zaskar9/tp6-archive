PCGRADES - GRADE MANAGEMENT
===========================
Two programs share this folder.

1. "Klasse" (DATEI.PAS), June 1993 to January 1994. Manages pupils
   and their grades, averages, report cards, printing.
   Includes: BACKGROU MACHRAHM COPYRIGH OUTPUTIN HELP LOAD SAVE
   DATINPUT DATOUTPU DURCHSCH HINZUFUE ZEUGNIS DATSUCHE LOESCHEN
   AUSWAHL ENTSCHEI (.INC)
   Data: *.NOT grade files (5A, DER, DOMINIQU, MICHAEL, NOTEN,
   TEST .. TEST8, TESTXY).

2. "Zusammenkunft" (KLASSE.PAS): attendance list for a class
   reunion. Data: KLASSE.DAT, MEN1.DAT. Build: KLASSE.EXE
   (Sept 1993). KLASSE.INF is an empty file from 2001.
   Unit: MYOBJECT.PAS (copy of UNITS).

GRINTPIC.EXE: graphics test program (source in PCXTOOLS).

OLD\  the first version of the grade program (May/June 1993):
      DATSEARC.INC, FILEINIT.INC, INFORMAT.INC and .NOT files,
      plus the ancestors ZEUGNIS.PAS and NOTEN.PAS (late 1992)
      and an older KLASSE.EXE.
